# Database leaks
## Data Breach Search Engines

- [greynoise](https://viz.greynoise.io/?ref=rayanle.cat) - Search for IPs, Tags, CVEs, vpn, dns...
- [Dehashed](https://www.dehashed.com/?ref=rayanle.cat) - You can search for your email if its leak in some databases of anything..
- [HaveIbeenPwned?](https://haveibeenpwned.com/?ref=rayanle.cat) - check if your email address is in a data breach
- [ScamSearch](https://scamsearch.io/?ref=rayanle.cat) - search to find phone, email, profile if is tobe a scammer.
- [Intelligence X](https://intelx.io/?ref=rayanle.cat) - Intelligence X is a search engine and data archive. · The search works with selectors, i.e. specific search terms such as email addresses, domains, URLs, IPs...
- [spycloud](https://portal.spycloud.com/endpoint/enriched-stats/[YOUR-MAIL]?ref=rayanle.cat) - put your mail in YOUR-MAIL.
- [weleakinfo](https://weleakinfo.io/?ref=rayanle.cat) - We Leak Info - Leaked Dehashed Databases, search for leaks.
- [breachdirectory](https://breachdirectory.org/?ref=rayanle.cat) - CHECK IF YOUR EMAIL OR USERNAME WAS COMPROMISED
- [leakcheck](https://leakcheck.io/?ref=rayanle.cat) - Find out if your credentials have been compromised
- [Findemail.io](https://findemail.io/?ref=rayanle.cat) - Find email addresses for given company.
- [LibraryOfLeaks](https://search.libraryofleaks.org?ref=rayanle.cat) - Search for leak documents, companies, people, database and more
- [LeakRadar](https://leakradar.io/?ref=rayanle.cat) - Instant search across 2 B+ plain-text info-stealer credentials; email, domain, metadata queries, monitoring & API
- [InfoStealers](https://infostealers.info/en/info?ref=rayanle.cat) - Indexes darknet-exposed infostealer logs and makes them searchable and actionable for security teams, investigators, researchers, and digital forensics professionals.
- [Leak-Lookup](https://leak-lookup.com/?ref=rayanle.cat) - Data breach search engine with over 3 billion records from 3000+ databases.
- [BreachDirectory](https://breachdirectory.org/?ref=rayanle.cat) - Check if your credentials have been compromised in data breaches.
- [Scylla.so](https://scylla.so/?ref=rayanle.cat) - Community-driven database breach search engine.
- [Leaked.domains](https://leaked.domains/?ref=rayanle.cat) - Search for domain-related leaked credentials and data.
- [WhiteIntel](https://whiteintel.io/?ref=rayanle.cat) - Dark web data leak search engine for threat intelligence.
- [PSBDMP](https://psbdmp.ws/?ref=rayanle.cat) - Pastebin dump search and monitoring platform.

## Tools to enumerate data leaks

- [Leaker](https://github.com/vflame6/leaker?ref=rayanle.cat) - Passive leak enumeration CLI tool that searches across 10 breach databases simultaneously.
